## 🚀 How to Run Any Project

```bash
# Navigate to the lecture folder
cd Lecture_XX_ProjectName

# Run with Maven
./mvnw spring-boot:run
```

Or import the folder into **IntelliJ IDEA / VS Code** and run the main application class.
